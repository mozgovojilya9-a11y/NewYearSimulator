# Aura Clicker — «Цитадель Ауры»

Roblox-симулятор на Rojo 7 + Luau. Правила проекта и цель — в
[CLAUDE.md](CLAUDE.md). Все числа, шансы, цены, рецепты, тексты и ID —
в `src/shared/Config.luau`. Сервер — источник истины.

## Игровой цикл

1. **Аура** (сила + валюта) — только от кликов, авто-клика и тренажёров.
   Стоишь на тренажёре — Аура капает раз в секунду сама, клики дают бонус.
2. **Урон** = база оружия × `AuraPower(Аура)` (`1 + log10(Аура+1) × 0.75`)
   × ребёрты × бонус сета брони × питомцы × пассы/бусты.
3. **Данж**: 20 комнат, босс каждые 5, каждый вход — новый забег с 1-й
   комнаты в своей полосе. Мобы дают **материалы 7 редкостей**
   (видит и поднимает только тот, кто бил; подбор — удержание E).
4. **Кузница**: из материалов крафтятся 16 видов оружия и 4 сета брони
   (шлем / нагрудник / поножи + бонус за 3 части) — с анимацией ковки.
5. **Ребёрт** у алтаря: сброс Ауры и рекорда, постоянный множитель
   Ауры и урона. Оружие, броня, материалы и питомцы остаются.
6. **Удержание**: ежедневная награда (7 дней), колесо удачи, 3 задания,
   уровень, яйца питомцев (слияние 3 → 1), бусты.

## Код

| Папка | Что там |
|---|---|
| `src/shared` | `Config`, `Format`, конструкторы моделей: `WeaponBuilder`, `ArmorBuilder`, `MaterialBuilder`, `PetBuilder` |
| `src/server` | `Main.server` (старт), `HubGenerator`/`HubService` (хаб, тренажёры), `DungeonGenerator`/`DungeonRuns`/`MobBuilder`/`MobAI` (данж), `ClickService` (клик, авто-клик), `LootService` (дроп), `CraftService` (кузница), `EquipmentService` (оружие и броня на персонаже), `PetService`, `StoreService` (Robux), `Passes`, `ProgressionService`, `RebirthService`, `TravelService`, `Bounds` (нельзя выпасть), `PlayerState`, `DataService` |
| `src/client` | `Combat` (клик), `Swing` (взмах), `MobFx` (анимации мобов, полоска босса), `LootFx` (дроп), `HubFx`, `Cosmetics` (питомцы), `Zone` (свет), `Prompts`, `ui/*` (HUD и окна) |

Запуск: `rokit install`, `rojo serve`, в Studio — плагин Rojo → Connect.
Для сохранений в Studio: Game Settings → Security → Enable Studio Access
to API Services. Для покупок — опубликованное место.

`src/shared/Config.luau` в поле `Id` нужной строки. Пока `Id = 0`, в
магазине и на тренажёрах написано «Скоро».

при следующем входе.

## Приёмка в Studio

1. Output без красных ошибок; нет засвета, все надписи читаются.
2. Из карты не выпасть ни в хабе, ни в данже (упал — мягкий телепорт).
3. На тренажёре Аура капает сама (плашка «Тренажёр xN · +N/сек»),
   клик и авто-клик работают, мобы Ауру не дают.
4. С мобов падают материалы разных редкостей, поднимаются только
   удержанием E, чужой дроп не виден.
5. Кузница крафтит оружие и броню с анимацией, всё видно на персонаже.
6. Взмах оружия при клике, на тренажёре и в бою (3 варианта по очереди).
7. Мобы детальные, ходят и бьют с красной вспышкой; боссы — красный круг
   на полу и полоска HP сверху.
8. Забег каждый раз с 1-й комнаты, «Рекомендуемый урон» на барьере и в HUD.
9. Магазин: все позиции на месте, с `Id = 0` — «Скоро».

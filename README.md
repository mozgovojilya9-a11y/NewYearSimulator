# Aura Clicker — «Цитадель Ауры»

Roblox-симулятор на Rojo 7 + Luau. Правила проекта и цель — в
[CLAUDE.md](CLAUDE.md). Все числа, шансы, цены, рецепты, тексты и ID —
в `src/shared/Config.luau`. Сервер — источник истины.

## Игровой цикл

Экшен-RPG с данжами (не кликер). Сила персонажа — уровень, снаряжение,
навыки и класс; все формулы в `Config`, итоговые статы считает
`StatService`.

1. **Данж**: 20 комнат, босс каждые 5, каждый вход — новый забег с 1-й
   комнаты в своей полосе. Мобы дают **опыт**, **Нано-кредиты 💠** и
   **материалы 7 редкостей** (видит и поднимает только тот, кто бил;
   подбор — удержание E).
2. **Уровень**: опыт за мобов, боссов и задания; за уровень — очко
   навыка, рост урона и HP, полное лечение.
3. **Кузница**: из материалов крафтятся оружие и броня (шлем / нагрудник
   / поножи + бонус за 3 части) — с анимацией ковки.
4. **Удержание**: ежедневная награда (7 дней), колесо удачи, 3 задания,
   бусты x2. Питомцев нет (убраны; старым игрокам — компенсация кредитами).

**Урон** = урон оружия × множитель уровня × бонус сета ×
пассы/бусты. У предметов есть уровень предмета, у игрока —
**Gear Score** (сумма по оружию и трём слотам брони, в HUD рядом с
уровнем). Темп (минута → уровень / этап / снаряжение) считает
`tools/pacing.py` — раздел «Темп прокачки» в конце.

## Код

| Папка | Что там |
|---|---|
| `src/shared` | `Config`, `Format`, `Assets` (модели из GameAssets), конструкторы моделей: `WeaponBuilder`, `ArmorBuilder`, `MaterialBuilder`, `PetBuilder` |
| `tools` | `pacing.py` — симулятор темпа прокачки по числам из `Config` (`--tune`, `--readme`) |
| `src/server` | `Main.server` (старт), `StatService` (все характеристики игрока), `HubGenerator`/`HubService` (хаб), `DungeonGenerator`/`DungeonRuns`/`MobBuilder`/`MobAI` (данж), `ClickService` (клик, авто-клик), `LootService` (дроп), `CraftService` (кузница), `EquipmentService` (оружие и броня на персонаже), `PetService`, `StoreService` (Robux), `Passes`, `ProgressionService`, `TravelService`, `Bounds` (нельзя выпасть), `PlayerState`, `DataService` |
| `src/client` | `Combat` (клик), `Swing` (взмах), `MobFx` (анимации мобов, полоска босса), `LootFx` (дроп), `Zone` (свет), `Prompts`, `ui/*` (HUD и окна) |

Запуск: `rokit install`, `rojo serve`, в Studio — плагин Rojo → Connect.
Для сохранений в Studio: Game Settings → Security → Enable Studio Access
to API Services. Для покупок — опубликованное место.

## Модели (GameAssets)

Свои модели клади в Studio в `ServerStorage/GameAssets/<Категория>/<Имя>`.
Rojo эту папку не трогает. При старте сервер копирует очищенную копию в
`ReplicatedStorage/GameAssets` (скрипты, звуки и всё «не-визуальное»
удаляются) и печатает в Output список моделей с размерами и тех, которых
не хватает. Нет модели — игра строит процедурную из деталей.

| Категория | Имена | Где используется |
|---|---|---|
| `Weapons` | `Weapon_Sword_1/2`, `Weapon_Spear_1/2`, `Weapon_Blaster_1/2/3` | оружие классов Клинок / Импульс / Стрелок: `_1` — обычные/необычные, старшие номера — редкие и выше (`Config.Assets.WeaponModels`). Модель с именем ровно как id оружия (например `BoneSword`) важнее таблицы. Tool можно: берутся только детали. |
| `Mobs` | `Boss_Juggernaut`, `Mob_SpiderBot`, `Mob_Mech`, `Mob_RedAndroid`, `Mob_Overseer`, `Mob_Robot`, `Mob_Android`, `Mob_BlueBot`, `Mob_Bot2` | мобы и боссы подземелья (`Config.Mobs`: какая модель, высота, перекраска) |
| `Props` | `Prop_Crate`, `Prop_Door`, `Prop_Lamp`, `Prop_Pipes`, `Prop_Hologram`, `Prop_Barrel`, `Prop_Misc_1…4` | декор хаба и подземелья (подбираются по размеру) |
| `Trainers` | `Trainer_Dummy`, `Trainer_Bag` (манекены полигона), `Trainer_Machine`, `Trainer_Refiner`, `Trainer_Weights` (декор) | полигон, фабрикатор, хаб |
| `Armor` | — | броня процедурная |

Иконки предметов рисуются из 3D-моделей автоматически; свою картинку
можно задать в `Config.Assets.Icons[id предмета] = "rbxassetid://..."`.

Если моб смотрит спиной вперёд — поставь ему `Turn = 180` в
`Config.Mobs.Defs`. Если оружие в руке развёрнуто не тем концом или держится не за ту
точку — поправь `Config.Assets.WeaponFit` (`Flip = true`, `GripAt`,
`Length`).

## Robux: что создать в Creator Dashboard

Creator Dashboard → твоя игра → **Monetization**. Созданный ID впиши в
`src/shared/Config.luau` в поле `Id` нужной строки. Пока `Id = 0`, в
магазине написано «Скоро».

### Game Passes → `Config.GamePasses`

| Ключ | Название | Цена, R$ | Что даёт |
|---|---|---|---|
| `VIP` | VIP | 199 | +20% опыта и кредитов, тег 👑 VIP над головой |
| `Damage2x` | x2 Урон | 149 | урон x2 навсегда |
| `Xp2x` | x2 Опыт | 149 | весь опыт x2 навсегда |
| `Credits2x` | x2 Кредиты | 149 | все нано-кредиты x2 навсегда |
| `LootLuck` | Удача добычи x2 | 199 | x2 шанс редких+ материалов |

| Key | Название | Цена, R$ |
|---|---|---|
| `CreditsSmall` / `CreditsMedium` / `CreditsLarge` | Горсть / Пачка / Сейф кредитов | 25 / 79 / 199 |

| `BoostXp15` / `BoostXp60` | x2 Опыт 15 / 60 мин | 25 / 69 |

Покупки продуктов обрабатываются идемпотентно: каждый `PurchaseId`
записывается в DataStore `AuraClicker_Purchases_v1`, повторный чек ничего
не выдаёт второй раз. Если игрок вышел до выдачи — Roblox повторит чек
при следующем входе.

## Приёмка в Studio

1. Output без красных ошибок; нет засвета, все надписи читаются.
2. Из карты не выпасть ни в хабе, ни в данже (упал — мягкий телепорт).
3. Мобы дают опыт и нано-кредиты, уровень растит урон и HP
   (баннер «Новый уровень!»).
4. С мобов падают материалы разных редкостей, поднимаются только
   удержанием E, чужой дроп не виден.
5. Кузница крафтит оружие и броню с анимацией, всё видно на персонаже.
6. Взмах оружия при клике и в бою (3 варианта по очереди).
7. Мобы детальные, ходят и бьют с красной вспышкой; боссы — красный круг
   на полу и полоска HP сверху.
8. Забег каждый раз с 1-й комнаты, «Рекомендуемый урон» на барьере и в HUD.
9. Магазин: все позиции на месте, с `Id = 0` — «Скоро».
